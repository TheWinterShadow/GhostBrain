> | Content Type | Filename Pattern | Example |

> | Tool/app | `Tool - Name.md` | `Tool - FTK Imager.md` |
> | Command reference | `Command - What It Does.md` | `Command - SCP EC2 Transfer.md` |
> | Course/study notes | `CourseName - Topic.md` | `CYSE 411 - Cheat Sheet.md` |
> | General reference | Descriptive name | `FastAPI Auth Patterns.md` |
>
> **Tags:** `#reference` + domain tags (`#code`, `#security`, `#food`, `#education`, etc.)
